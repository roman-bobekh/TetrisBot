# TetrisBot

Tetris in Processing with a bot that plays it. For each piece (and the hold piece), the bot searches the possible placements and picks the one with the best board evaluation (holes, height changes, blocks above holes).

The plain game without the bot is in `Tetris/`.

## Run

Open `TetrisBot.pde` in [Processing](https://processing.org) (with the Sound library installed) and press Run.
